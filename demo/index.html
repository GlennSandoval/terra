terra is a super customizable framework for creating and analyzing biological simulations. It's open-source and licenced under MIT.

Usage

Including terra

Getting started is as easy as including the script!

<script src="terra.min.js"></script>

terra can also be used as a module with most popular module systems. ?

import {Terrarium, registerCA, registerCreature} from 'terra';

Creating creatures

Let's create a simple creature with terra.registerCreature. Each creature requires a type.

terra.registerCreature({
  type: 'firstCreature'
});

This creature is valid, but it's pretty boring. To make a more interesting creature, let's override some of the default attributes and methods.

terra.registerCreature({
  type: 'secondCreature',
  color: [120, 0, 240],
  sustainability: 6,
  reproduceLv: 1
});

We've just created a purple creature that only eats if 6 or more plants are around it. These creatures basically seek out an edge or corner and die there.

Creating the environment

To run a simulation, register the plant type, create a 25x25 grid, and fill it with 10% purple creatures and 90% plants.

terra.registerCreature({
  type: 'simplePlant',
  color: [0, 120, 0],
  size: 10,
  initialEnergy: 5,
  maxEnergy: 20,
  move: false,
  reproduceLv: 0.65,
  wait() {
    this.energy += 1;
  }
});

const ex1 = new terra.Terrarium(25, 25, {id: 'ex1'});
ex1.grid = ex1.makeGridWithDistribution([['secondCreature', 10], ['simplePlant', 90]]);

Running a simulation

Terrariums have a few methods that allow you to interact with the simulation. Let's animate it and see how it does for the first 300 steps.

ex1.animate(300);

That's all there is to it! Though it's possible to generate complex behaviours by simply overriding default values, the real fun comes when you realize that creatures are entirely customizable.

Examples

Conway's Game of Life ?

terra.registerCA({
  type: 'GoL',
  color: [255, 255, 255],
  colorFn() {
    return this.alive ? `${this.color},1` : '0,0,0,0';
  },
  process(neighbors) {
    const aliveNeighbors = neighbors.filter(
      ({creature}) => creature && creature.alive,
    ).length;
    const nextAlive = aliveNeighbors === 3 || (this.alive && aliveNeighbors === 2);
    const changed = nextAlive !== this.alive;
    this.alive = nextAlive;
    return changed;
  },
}, function () {
  this.alive = Math.random() < 0.5;
});

const gameOfLife = new terra.Terrarium(25, 25, {periodic: true});
gameOfLife.grid = gameOfLife.makeGrid('GoL');
gameOfLife.animate();

Cyclic Cellular Automaton ?

terra.registerCA({
  type: 'cyclic',
  colors: ['255,0,0,1', '255,96,0,1', '255,191,0,1', '223,255,0,1', '128,255,0,1', '32,255,0,1', '0,255,64,1', '0,255,159,1', '0,255,255,1', '0,159,255,1', '0,64,255,1', '32,0,255,1', '127,0,255,1', '223,0,255,1', '255,0,191,1', '255,0,96,1'],
  colorFn() {
    return this.colors[this.state];
  },
  process(neighbors) {
    const nextState = (this.state + 1) % this.colors.length;
    const changes = neighbors.some(
      ({creature}) => creature && creature.state === nextState,
    );
    if (!changes) return false;
    this.state = nextState;
    return true;
  },
}, function () {
  this.state = Math.floor(Math.random() * 16);
});

const cyclic = new terra.Terrarium(50, 50, {cellSize: 6, periodic: true});
cyclic.grid = cyclic.makeGrid('cyclic');
cyclic.animate();

Brutes and Bullies

terra.registerCreature({
  type: 'plant',
  color: [0, 120, 0],
  size: 10,
  initialEnergy: 5,
  maxEnergy: 20,
  wait() {
    this.energy += 1;
  },
  move: false,
  reproduceLv: 0.65
});

terra.registerCreature({
  type: 'brute',
  color: [0, 255, 255],
  maxEnergy: 50,
  initialEnergy: 10,
  size: 20
});

terra.registerCreature({
  type: 'bully',
  color: [241, 196, 15],
  initialEnergy: 20,
  reproduceLv: 0.6,
  sustainability: 3
});

const paTerrarium = new terra.Terrarium(25, 25);
paTerrarium.grid = paTerrarium.makeGridWithDistribution([
  ['plant', 50],
  ['brute', 5],
  ['bully', 5],
]);
paTerrarium.animate();

Creatures

Register creatures with terra.registerCreature(options, init) and cellular automata with terra.registerCA(options, init).

The following methods and attributes can be passed in an object as the first argument:

Required

  • string type

    Creature type used later when creating a grid with makeGrid( ).

Optional

  • int actionRadius

    A creature's vision and movement range for each step.

    • Default: 1

  • char character

    ASCII character used to visually represent a creature.

    • Default: undefined (fills cell)

  • Color color

    RGB component array or comma-separated color string.

    • Range: [0, 255]
    • Default: random

  • function colorFn

    How a creature's color is determined at each step.

    • Returns: string of comma-separated RGBA components.

  • float efficiency

    Conversion ratio of food to energy. Food energy × efficiency = gained energy.

    • Default: 0.7

  • float initialEnergy

    Energy level assigned when a creature is created.

    • Range: (0, maxEnergy]
    • Default: 50

  • function isDead

    Determines whether a creature should be removed at the beginning of a step.

    • Returns: boolean

  • float maxEnergy

    Maximum energy that a creature can have; excess energy is discarded.

    • Default: 100
    • Minimum: 0

  • function move

    How a creature moves.

    • Parameters: {coords, creature} [] neighbors
    • Default: Look for edible creatures; if none are found, look for open spaces to move to; if none are found, wait.
    • Returns: {x, y, creature, successFn} || false

  • float moveLv

    Energy threshold for movement in the default process behavior.

    • Default: 0
    • Range: [0, 1]

  • function process

    Called for each creature on each simulation step.

    • Parameters: neighbors, x, y
    • Default: Reproduce or move according to energy thresholds, otherwise wait.
    • Returns: an action object, a boolean change indicator, or undefined.

  • function reproduce

    How a creature reproduces.

    • Parameters: {coords, creature} [] neighbors
    • Default: Look for neighboring open space; if any exists, randomly place a new creature and lose energy equal to the child's initialEnergy.
    • Returns: {x, y, creature, successFn, failureFn} || false

  • float reproduceLv

    Energy threshold for reproduction in the default process behavior.

    • Default: 0.7
    • Range: [0, 1]

  • int size

    A creature's size; by default, creatures can only eat creatures smaller than them.

    • Default: 50

  • int sustainability

    Number of visible food sources needed before a creature will eat.

    • Default: 2
    • Range: (0, 16 × actionRadius - 8]

  • function wait

    What happens when a creature waits.

    • Default: Creature loses 5 energy.

  • * *

    The best part about creatures is that you can add whatever you want to them! In addition to overriding any of the above properties, creatures will accept any methods and properties you throw at 'em.

The optional second argument to terra.registerCreature or terra.registerCA initializes each new creature. For example, this initializer assigns a random state to each cell in the Cyclic Cellular Automaton:

function initCyclic() {
  this.state = Math.floor(Math.random() * 16);
}

Whenever a new creature is created of type 'cyclic', it will be randomly assigned a state of 0 to 15.

Terrarium

Terrariums are where the action happens. They're initialized with the following constructor:

const t = new terra.Terrarium(width, height, {
  id,
  cellSize,
  insertAfter,
  neighborhood,
  periodic,
  trails,
  background,
});

Required

  • int width

    Number of cells in the x-direction.

  • int height

    Number of cells in the y-direction.

Options

  • string id

    ID assigned to the generated canvas.

  • int cellSize

    Pixel width of each cell. Defaults to 10.

  • Element insertAfter

    Element after which the canvas is inserted. By default, the canvas is appended to document.body.

  • boolean periodic

    When true, neighbors wrap around the grid edges.

  • string neighborhood

    Set to vonneumann to use von Neumann neighbors; defaults to Moore neighbors.

  • number trails

    Trail persistence from 0 to 1. Requires a background color.

  • Color background

    RGB background color, also used when drawing trails.

Terrariums expose grid creation and drawing methods. Using our terrarium t:

t.grid = t.makeGrid('creatureType');
t.grid = t.makeGridWithDistribution([
  ['creatureType', 80],
  ['anotherType', 20],
]);
t.grid = t.step(steps);
t.draw();
t.animate(steps, fn);
t.stop();
t.destroy();

makeGrid creates a grid from a creature type, a row-major array, or a coordinate callback. makeGridWithDistribution uses weighted percentages. step returns the next grid, false when a step makes no changes, or undefined when no steps run. animate stops when the grid no longer changes or when its step limit is reached.
